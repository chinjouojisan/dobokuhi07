# カコモと学ぶ 決算チャレンジ 土木費編

加古川市 令和7年度一般会計決算「土木費」(約111.3億円)を、クイズと予算判断
シミュレーションで学べる単一HTMLファイルのPWAです。

## この款のポイント

- 決算総額(約111.3億円)のうち、6つの「項」では都市計画費(約86.9億円)が
  突出して大きく、全体の約78%を占めます(主因は下水道事業会計への繰出金等)。
- seika_houkokusho側の事業一覧は23件、合計約42.7億円で、カバー率は約38%です。
- 全23事業とも就学援助のような法律上の給付義務はなく、「法定給付」に該当する
  事業はありません(全て裁量事業として分類)。
- 翌年度繰越額は約5.2億円、不用額は約4.1億円と、いずれも他の款と比べて
  大きめです(複数年度にまたがる工事が多いため)。

## 構成

1. **入口クイズ層**(37問、2択): 基礎知識5問+予算vs決算23問+特別トリビア9問
   (道路補修事業・市営住宅整備事業の急増理由、公園建設事業の急減理由、
   街路事業・総合交通政策事業のベンダー集中、シルバー人材センターの
   複数事業受託、23事業一覧には出てこない「加古川駅周辺再整備基金積立
   事業(20億円)」「下水道事業会計支出事業(23.4億円)」の2件を追加)
2. **本編シミュレーション層**: 23事業。全て裁量事業(法定給付なし)
3. **答え合わせ層**: 未実装(他の款と同様)
